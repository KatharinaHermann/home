# Where to search

Pick retailers that deliver to the user's address. Search 3+ different shops per request so the shortlist isn't one-shop-only. Prefer the retailer's own product page over aggregators when verifying price and dimensions.

Retailer lists change; if a shop doesn't deliver to the user or its pages won't load, move on.

## Query patterns

- `<item> <key dimension> <style/colour> site:<retailer domain>` – e.g. `bookshelf 80 cm wide oak site:ikea.com`
- `<item> <width> cm <material> <colour>` in the local language
- `best <item> for small spaces 2026 review` – for category overviews, then go to the shops
- For second-hand: search the classifieds with the user's city and a radius, and the designer name if a classic fits (e.g. "String Regal", "Muuto", "USM").

## Verification checklist per candidate

- [ ] Product page opened and readable
- [ ] Dimensions taken from the page (not a snippet), units clear
- [ ] Price + shipping to the user's postcode, in their currency
- [ ] In stock / delivery estimate
- [ ] Variant/colour that matches the space brief exists
- [ ] Return policy noted (bulky items: who pays return shipping?)
- [ ] Rating + review count, one honest con
- [ ] Shop looks legitimate (see `checkout.md`)
